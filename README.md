# Geospatial-Urban-Analytics
Geospatial Analytics portfolio using QGIS to map market gaps, infrastructure risks, and demographic trends through KDE and Buffer Analysis.

# Project Overview
This repository contains a comprehensive geospatial portfolio developed using QGIS. The project translates complex spatial data into actionable insights for urban resilience, market strategy, and social policy. By integrating satellite imagery, OpenStreetMap (OSM), and Census of India data, I identified critical "service gaps" where infrastructure fails to meet safety and social needs.

# Repository Structure
01_Spatial_Data_and_Projects: Contains Spatial_Data.zip. This includes all .qgz project files and complete Shapefile sets (.shp, .dbf, .prj) for the Mumbai and Ward analyses.

02_Visual_Outputs: High-resolution map exports (JPG/PDF) and QGIS print layout templates (.qpt).

03_Analysis_Reports: Professional reports detailing the findings for Urban Resilience and National Demographic Trends.

# Key Technical Skills
Spatial Analysis: Kernel Density Estimation (KDE), Buffer Analysis (5m & 500m), Proximity Mapping.

Data Engineering: Spatial joins, attribute data cleaning, and hierarchical data organization.

Cartography: Choropleth mapping, heatmaps, and professional layout design.

# Featured Case Studies
1. Urban Resilience & Service Gap Analysis
Problem: Rapid urbanization often leaves critical infrastructure (hospitals/schools) outside of emergency response zones.

Insight: A 500m Buffer Analysis revealed that the ward’s primary hospital and several schools are in an "Unsafe Zone" regarding fire station proximity.

Impact: Provided a data-backed roadmap for municipal authorities to prioritize new satellite emergency posts.

2. Mumbai Market Hotspot Analysis
Method: Applied KDE to restaurant/café POI data.

Result: Identified a "West-Coast Bias" and significant underserved market opportunities in the Eastern Harbour industrial belt.

3. National Demographic Disparities
Analysis: Engineered choropleth maps of India’s Sex Ratio using Census data.

Finding: Visualized a stark North-South divide (e.g., Kerala at 1084 vs. Haryana at 879), highlighting regional socio-economic clusters.

# How to Use This Repository
To replicate the analysis or view the technical layers:

Download Spatial_Data.zip from the 01_Spatial_Data_and_Projects folder.

Extract the folder locally.

Open the .qgz project files in QGIS to view layers, symbology, and analysis buffers.
